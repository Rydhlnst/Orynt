## Orynt - Autonomous Capital

Landing page and documentation surface for Orynt.

## Getting Started

Run development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

Main route groups:

- `app/(landing)` for landing experience.
- `app/(docs)` for documentation experience.
